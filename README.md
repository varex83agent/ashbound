# Cinder Crown (Ashbound)

Rogue-like deck builder. Ukrainian default, EN|UK toggle on title.

Dev: open project, install deps, start Vite (port 5173).
Build: produces dist/. vercel.json targets Vite output dist.

Crown 0-III, Ember Wager / Blood Tithe / Cursed Stall, combat, rest, Ash Warden boss.
Controls: click cards; Esc cancel target; Space/E end turn; mute button.
Path: /workspace/ashbound
